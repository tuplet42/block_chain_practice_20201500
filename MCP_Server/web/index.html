Upbit Beginner MCP

초보 사용자를 위한
Upbit MCP Web Demo

브라우저에서 버튼을 누르면 Web Backend가 MCP client 역할을 수행하고, Upbit MCP Server의 tool을 호출하여 현재가, 호가창, 마켓 정보, 초보자용 요약을 표시합니다.

1
브라우저 UI 마켓 코드/코인명 입력 후 실행
2
Web Backend 요청을 받아 MCP client 생성
3
MCP Server tool 목록 제공 및 tool 실행
4
External API Upbit Quotation API 조회
5
Tool Result 결과를 UI에 표시

Tool Discovery

MCP Server가 제공하는 tool 목록을 조회합니다. JSON 원문이 아니라 확인하기 쉬운 텍스트 목록으로 표시합니다.

아직 tool 목록을 조회하지 않았습니다.

업비트 마켓 코드 찾기

코인 이름, 영문명, 심볼을 입력하면 Upbit에서 사용하는 마켓 코드를 찾아줍니다.

초보자용 요약

현재가, 변동률, 거래대금, 호가 스프레드, 시장 경보 정보와 초보자 해석을 한 번에 확인합니다.

마켓 코드 설명 스프레드 해석 거래 활발도

호가창 조회

매도호가, 매도잔량, 매수호가, 매수잔량을 상위 n단계까지 조회합니다.

주요 코인 비교

여러 Upbit 마켓의 현재가, 24시간 변동률, 24시간 거래대금을 비교합니다.

빠른 실행

발표/시연용으로 자주 사용하는 코인을 선택한 뒤 요약 또는 호가창을 바로 조회합니다.

결과

조회 결과는 아래 영역에 표시됩니다. `[server]`, `[tool]`, `[arguments]` 같은 개발용 메타정보는 표시하지 않습니다.

아직 실행된 tool이 없습니다.
원하는 기능을 선택해서 실행해보세요.
